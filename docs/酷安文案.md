# 酷安发布文案（v1.0.0-demo）

---

**🚀 基本信息**

- 类型：MIUI / HyperOS 字体主题（MTZ，免 Root）
- 名称：苹方 SF Pro（PingFang SF Pro）
- 版本：v1.0.0-demo
- 构成：中文取**苹方 PingFang SC**，西文 / 数字 / 半角标点取 **SF Pro**
- 字重：单文件变量字体，`wght` **150–700** 连续可调，12 个档位

**✨ 本次亮点**

1. **一个文件搞定全部字重** —— 不是塞 7 个 TTF，而是把 7 个逐点兼容的母版合并成一个变量字体，
   系统拖动字重滑块时真正连续变化。
2. **中西文各取所长** —— 中文骨架用苹方（约 29,180 码位），西文数字用 SF Pro（1,485 码位，
   opsz 固定 17、upem 对齐 1000），中英混排不再「西文发飘」。
3. **字重是算出来的，不是简单加粗** —— 苹方 6 个官方字重轮廓互不兼容，所以只保 Regular 的拓扑，
   逐点沿法线外扩 / 内缩并做碰撞钳制，用 Apple 真身实测的墨量当目标做 Newton 迭代收敛。

**📦 只有一个包**

| 包 | 体积 | 适用 |
|---|---|---|
| `PingFang-SFPro_v1.0.mtz` | 21.2 MiB | 全部机型，免 Root，主题商店导入 |

没有 Root 模块、不含 emoji、不含字重分档包 —— 这是 Demo，先把主链路跑通。

**⚠️ 几个一定会被问的**

| 问题 | 回答 |
|---|---|
| 只有 400 是真字重？ | 是。100/200/300/500/600/700 都是基于 Regular 的几何合成，收笔细节和 Apple 真身有差异 |
| 为什么细字重感觉偏粗？ | 碰撞钳制会让极细笔画提前停止收缩，100 档面积误差约 8%，这是已知限制 |
| 会用坏系统 / 卡开机吗？ | 它是主题包，走主题引擎，随时可以切回默认字体；但**请先备份**，本 Demo 没有真机长测 |
| 为什么不动 emoji？ | 字体和 emoji 是两条通道，混在一起签名和回退更难排查。emoji 用作者另一个项目 chiron-apple-emoji |
| 酷安、微博字体没变？ | 这类 App 自带字体或渲染器，任何系统级字体替换都不生效 |
| 提示「主题不兼容」？ | MTZ 签名策略因机型和系统版本而异，需要自己重签再导入 |
| 字重滑块动不了？ | 先确认 `description.xml` 的 `<fontWeight>` 与字体 `fvar` 实例一致；本包已对齐 150–700 step 50 |

**🔧 装完怎么验**

1. 设置 → 主题壁纸 → 我的 → 主题 → 本地导入 → 选 `PingFang-SFPro_v1.0.mtz`；
2. 应用后重启一次；
3. 设置 → 显示 → 字体，能看到「苹方 SF Pro」，拖动字重 150 → 700 字形明显变粗；
4. 随便打开一个中文为主的页面：中文应为苹方字形（横细竖粗、口字收笔平），数字与英文为 SF Pro 字形；
5. 想回退：同页面切回默认字体即可。
