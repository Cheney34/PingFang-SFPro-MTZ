# 构建与发版

## 一、环境

| 项 | 要求 |
|---|---|
| Python | 3.10+（本项目在 3.14.6 上验证） |
| 依赖 | `pip install -r requirements.txt` —— fonttools 4.68+、numpy、Pillow、brotli、zopfli |
| 磁盘 | 源字体约 110 MB，`work/` 中间产物约 120 MB，峰值内存约 2 GB |
| CPU | 04 / 05 两步吃满单核为主，全流程 10–15 分钟 |

## 二、七个步骤

```bash
python scripts/01_fetch_sources.py    # 1. 下载源字体
python scripts/02_prepare_sources.py  # 2. 实例化 + 缩放 + 按码位裁剪
python scripts/03_validate_synth.py   # 3. 合成算法自检（可选）
python scripts/04_build_masters.py    # 4. 合成 7 个 CJK 母版（约 9 分钟）
python scripts/05_build_vf.py         # 5. 合并 + varLib 构建 + 后处理
python scripts/06_previews.py         # 6. 渲染预览图
python scripts/07_package_mtz.py      # 7. 打包 MTZ
```

### 各步产出

| 步骤 | 产出 | 关键点 |
|---|---|---|
| 01 | `src-pingfang/ttf/*.ttf`（6 档）、`src-sfpro/**/sf-pro.ttf` | 苹方走 git clone，失败回落 codeload zip；SF Pro 走 maisfontes 的 token 流程 |
| 02 | `work/pf/pf-{100..600}.ttf`、`work/sf/sf-{100..700}.ttf` | SF Pro 按 `wght` 实例化、`opsz` 固定 17、upem 2048→1000；两边码位互补，保证 7 个母版字形集合一致 |
| 03 | — | 面积-距离单调性、绕向探测自检 |
| 04 | `work/masters/cjk-{100..700}.ttf` | 只保苹方 Regular 的拓扑，逐点法线外扩 / 内缩 + 碰撞钳制 + Newton 迭代 |
| 05 | `dist/fonts/Roboto-Regular.ttf` | `merge` 中西文 → `varLib.build(optimize=True)` → 改 name / OS/2 / hhea / post / GDEF / STAT，删 DSIG |
| 06 | `dist/preview/*` | Pillow 画 1080×1920 jpg + 285×74 png，用构建出的 VF 自己渲染 |
| 07 | `dist/PingFang-SFPro_v1.0.mtz` | `description.xml` + 字体 + 预览图，zip store 结构对齐 Chiron-Merriweather |

## 三、发版前自查清单

构建完成后逐项确认（本项目 v1.0.0-demo 的实际数值写在括号里）：

- [ ] `fvar` 轴 150 / 400 / 700，实例 12 个，与 `description.xml` 的 `<fontWeight>` **完全一致**（150–700 step 50）
- [ ] `OS/2.usWeightClass == 400`，typo 880 / -220，win 1060 / 340，`fsSelection = 0b11000000`
- [ ] `hhea` ascender 1060 / descender -340 / lineGap 0
- [ ] `name` 表 1/4/16 = `PingFang SF Pro`，6 = `PingFangSFPro-Regular`
- [ ] 无 `DSIG`（否则主题引擎可能拒收）
- [ ] 每个实例都能 `instancer.instantiateVariableFont` 且面积比单调（150:0.309 → 700:1.533）
- [ ] 渲染墨量随字重单调递增（2.13% → 7.16%）
- [ ] 轮廓无损坏（`192,994` 条中 300–500 档为 0）
- [ ] `description.xml` 可被 `ElementTree` 解析，`preview` 资源路径与包内一致
- [ ] 预览图文字不溢出（bbox 在边距内）
- [ ] `sha256sum` 生成 `.sha256` 并随附件发布

## 四、发版流程

```bash
# 1. 打 tag 并推
git tag -a v1.0.0-demo -m "v1.0.0-demo: first demo"
git push origin main --tags

# 2. 建 Release（附件走本机 dist/，不入库）
#    tag: v1.0.0-demo
#    title: 苹方 × SF Pro 变量字体主题 v1.0.0-demo
#    正文: docs/release-notes.md
#    附件: dist/PingFang-SFPro_v1.0.mtz、dist/PingFang-SFPro_v1.0.mtz.sha256
```

> ⚠️ 附件含 Apple 专有字形。发布前请确认你接受由此带来的风险；本仓库默认把
> `dist/` 和 `*.mtz` 都列进 `.gitignore`，仓库本身不含任何字体二进制。

## 五、常见坑

| 现象 | 原因 / 处理 |
|---|---|
| `VarLibValidationError: location out of bounds` | 母版位置超出轴范围。100 档母版钉到轴端点 150 再构建 |
| 合成字变细 / 面积误差 200%+ | 轮廓绕向相反（如 `uni56DB`「四」），法线朝内。用「沿法线跳 3 单位是否落在墨内」探测并翻转 |
| `AttributeError: calcIntBounds` | `glyf.recalcBounds` 要求 `GlyphCoordinates` 而非 list |
| 细字重收敛不到目标 | 碰撞钳制触发，属于预期；100 档残余误差 8.1% |
| 装上去字重档位和系统对不上 | `description.xml` 的 `<fontWeight>` 必须与 `fvar` 实例逐一对齐 |
| 提示主题不兼容 | MTZ 签名策略因机型而异，需重签 |
